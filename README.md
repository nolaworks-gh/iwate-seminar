# いわてセミナー暦

岩手県内の企業向けセミナーをまとめて検索できるポータルサイトです。GitHub Pages で公開しています。

## 仕組み

- `index.html`：サイト本体。`data/events.json` を読み込んで表示します。
- `data/events.json`：掲載しているセミナーのデータ。
- `data/sources.json`：毎週巡回する情報源の一覧。
- `COLLECTING.md`：毎週の収集手順と掲載ルール。

## 毎週の更新

1. 毎週、自動収集が `COLLECTING.md` に従って新しいセミナーを集め、プルリクエストを作ります。
2. 運営者がプルリクエストの本文と `data/events.json` の差分を確認します。載せたくない行があれば、そのブランチで削除します。
3. 問題なければマージします。数分でサイトに反映されます。

## 手で1件追加・修正するとき

GitHub の画面で `data/events.json` を開き、鉛筆アイコンから編集します。書き方は `COLLECTING.md` の「1件の書き方」を参照してください。
